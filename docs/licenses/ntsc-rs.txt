Atlas CRT's tape stage (src/vhs.wasm, built from native/vhs) is the ntsc-rs core library by
valadaptive, compiled to WebAssembly, unchanged:
https://github.com/valadaptive/ntsc-rs (crates/ntscrs, version 0.9.7, commit 8cfc510)

That library is offered under MIT, ISC or Apache-2.0. Atlas CRT uses it under the MIT license,
reproduced below. By its own account, ntsc-rs is a port of ntscqt by JargeZ, a GUI for ntsc by
zhuker, itself a Python port of composite-video-simulator by joncampbell123.

The compiled file also contains these crates, each used here under its MIT option:
fearless_simd by Raph Levien and contributors, hifijson by Michael Färber, and num_enum by Daniel
Wagner-Hall, Daniel Henry-Mantilla and contributors.
